# 🤖 答题机器人使用手册（koishi-plugin-hidamari-question v0.2.6）

> 适用于已部署到 fnOS 的答题机器人。群聊直接发送 **`/指令`** 即可（不必 @）；**@机器人** 时带不带 `/` 都可以。私聊可直接 `/指令`。机器人回复指令时会 **@发送者**。

---

## 一、指令总览

群聊发送 `/指令` 即可；@机器人时带不带 `/` 都可以。别名写在括号里。管理员由 `adminQQ` 与群内添加名单决定，超级管理员由 `superAdminQQ` 决定。

### 账号

| 指令 | 说明 | 权限 |
|---|---|---|
| `/注册` | 注册账号（昵称自动读取当前群名片/群昵称，QQ 号自动识别） | 所有人 |
| `/改名 <新昵称>` | 修改自己的昵称 | 已注册 |
| `/我的账号` | 查看自己的注册信息 | 所有人 |
| `/注销` | 注销账号（答题记录仍保留） | 已注册 |
| `/答题记录` | 查看自己的答题记录（按 QQ，注销后仍可查看） | 所有人 |

### 抢答 · 作答

| 指令 | 说明 | 权限 |
|---|---|---|
| `/回答 <答案>` | 作答当前题目（选择题填字母 A/B/C…，填空题填内容） | 已注册 |
| `/A`～`/H` | 快捷作答（游戏进行中时，等价于 `/回答 A`） | 已注册 |

### 抢答 · 管理

| 指令 | 说明 | 权限 |
|---|---|---|
| `/开始抢答 [题库名]` | 开始一局答题 | **仅管理员** |
| `/结束本题` | 立即结束当前题（公布答案并进入下一题） | **仅管理员** |
| `/跳到 <题号>`（`/快进`） | 快进到指定题（中间题不结算） | **仅管理员** |
| `/结束抢答` | 结束整局答题（自动公布答案 + 结算明细） | **仅管理员** |
| `/答题题目` | 查看当前可用题库列表 | 所有人 |
| `/用户列表` | 查看所有已注册用户（昵称 + QQ） | **仅管理员** |
| `/管理员列表` | 查看超级管理员 / 配置管理员 / 群内添加 | **仅管理员** |
| `/添加管理员 <QQ>` | 添加管理员（也可 @对方） | **仅超级管理员** |
| `/移除管理员 <QQ>` | 移除群内添加的管理员 | **仅超级管理员** |

### 每日发题

| 指令 | 说明 | 权限 |
|---|---|---|
| `/每日发题`（`/每日一题`） | 查看每日发题状态 | 所有人 |
| `/每日发题 开启 [题库]` | 开启本群每日发题 | **仅管理员** |
| `/每日发题 关闭` | 关闭每日自动发题 | **仅管理员** |
| `/每日发题 时间 HH:mm` | 设置每天发题时间 | **仅管理员** |
| `/每日发题 结算 HH:mm` | 设置每天结算时间 | **仅管理员** |
| `/每日发题 题数 N` | 每天从题库按顺序取几题（1～20） | **仅管理员** |
| `/每日发题 题库 名称` | 指定总题库（会重置进度游标） | **仅管理员** |
| `/每日发题 现在发` | 立即发今日题（已发过则重发同一批） | **仅管理员** |
| `/每日发题 现在结算` | 立即结算并公布答案 | **仅管理员** |
| `/每日回答 A B C`（`/日答`） | 一条消息回答当日全部每日题 | 已注册 |

### 跨群

| 指令 | 说明 | 权限 |
|---|---|---|
| `/跨群绑定 <群号>`（`/同步群`） | 把本群与其他群绑在一起，开局/切题同步 | **仅管理员** |

### 休眠

| 指令 | 说明 | 权限 |
|---|---|---|
| `/休眠` | 立即卸载题库、回收空闲房间，降低内存占用 | **仅管理员** |
| `/唤醒` | 立即加载题库，退出休眠 | 所有人 |
| `/休眠状态` | 查看当前是否休眠、题库是否在内存中 | 所有人 |

## 二、使用流程

### 1. 注册账号（首次使用）

```
@机器人 /注册
```
- 昵称自动取**当前群名片**（未设置则取群昵称/平台昵称）
- 账号按 QQ 号唯一，**跨群通用**（积分、答题记录共享）
- 回复示例：
  ```
  注册成功！
  昵称：小明
  QQ：123456789
  现在可以参与答题了，祝你好运！
  ```

### 2. 开始答题（管理员）

```
@机器人 /开始抢答
```
- 回复题库信息 + 第一道题
- 可选参数：`/开始抢答 题库名`（指定题库，本地题库模式下按 `guild` 字段匹配）
- 非管理员会收到：`你没有权限执行此操作，需要管理员`

### 2.1 跨群同步（管理员）

```
@机器人 /跨群绑定 123456789
@机器人 /跨群绑定 111111 222222
```
- 在其中一个群绑定另一个（或多个）群号
- 之后在任一绑定群 `/开始抢答`，其他群会同步出同一套题
- 两个群都在的成员，在哪边 `/回答` 都算同一局（每人每题只记一次，后答覆盖）
- `/结束本题`、`/跳到`、`/结束抢答` 也会同步到所有绑定群
- 答题进行中不能改绑定；结束后用 `/跨群解绑` 解除
- `/跨群状态` 可查看当前绑定

### 2.2 每日发题（管理员配置，全员作答）

从指定总题库**按顺序**每天取出若干题，一次性发到群里；成员用**一条消息**答完全部题；到点公布答案并计分。

```
@机器人 /每日发题 开启 向阳王
@机器人 /每日发题 时间 09:00
@机器人 /每日发题 结算 21:00
@机器人 /每日发题 题数 5
```

```
@机器人 /每日回答 A B C D E
```

- 选择题填字母，多题用空格分隔；填空题内容含空格时用逗号：`/每日回答 苍树梅,B,东边`
- 重复提交以最后一次为准
- 题库按顺序往下取，取完一轮会从头循环
- `/每日发题 现在发` / `现在结算` 用于补发或提前结算
- 关闭后不再自动发新题，当日已发出的仍可作答、到点仍结算

### 3. 作答

```
@机器人 /回答 A          ← 选择题填字母（也可直接发 /A）
@机器人 /回答 正确答案    ← 填空题填内容
```
- 作答后**不即时判对错**，会 **@你** 并回复：`已收到你的答案，作答时间结束后公布结果`
- 同一题重复作答**以最后一次为准**
- 同一账号同一时间默认只能在一个群作答；**已跨群绑定的群算同一局**，两群都在的成员在哪边作答都可以
- **快捷作答**：游戏进行中先 @机器人 再发送 `/A`~`/H` 即可作答，无需输入 `/回答`
- 出题提示：`作答：先 @我 再发送 /A ~ /E（或 /回答 对应字母）`

### 4. 公布答案

每题作答时间结束（`autoNext` 配置，云端默认 **180 秒 = 3 分钟**）后自动公布：

```
本题作答结束，正确答案：C. 紫色内裤无装甲形态
```
- 选择题附带选项编号（A/B/C…）
- **不公布谁对谁错**
- 答对者后台获得积分（`monetary`），连续答对额外加分
- **3 分题**：最先作答的 5 人答对得满分，其余答对基础分减半（连击另计）
- 无人作答时显示：`无人作答，正确答案：…`

### 5. 管理员快捷操作

```
/结束本题    ← 立即公布当前题答案并进入下一题（无需等待 3 分钟）
/结束抢答    ← 结束整局：自动公布当前题答案 + 输出结算明细
```
- `/结束本题` 回复顺序：`已结束本题` → 公布答案 → 下一题
- `/结束抢答` 自动公布当前题答案，并输出**每个作答者的昵称及答对/答错数量**：
  ```
  答题结束 结算统计

  题目：B站鬼畜区送分题
  详情：本地演示题目

  作答详情：
  小明（123456）答对 3 次，答错 1 次
  小红（654321）答对 1 次，答错 2 次

  参与人数：2
  总答对次数：4
  总答错次数：3
  ```
- 全部题目答完后也会自动输出同样的结算明细

## 三、指令详解

### `/注册`
- 无需参数，昵称自动获取
- 已注册用户（同一 QQ）重复 `/注册` 会提示已注册，**不重复添加账号**：
  ```
  你已注册过了！
  昵称：小明
  QQ：123456789
  如需修改昵称请发送 /改名 新昵称
  ```
- 修改昵称请使用 `/改名 新昵称`

### `/改名 <新昵称>`
- 修改自己的昵称（1~20 字）
- 需先注册；账号（QQ 号）不变

### `/我的账号`
- 查看当前账号昵称和 QQ 号

### `/注销`
- 删除自己的注册账号（`answer_user`），之后需重新 `/注册` 才能答题
- **答题记录不会删除**，仍可用 `/答题记录` 按 QQ 查看历史
- 注销后会清理进行中的游玩状态锁

### `/答题记录`
- 按当前 QQ 号查询历史答题记录（含昵称、QQ、每题对错与所作答案）
- **无需已注册**；账号注销后仍可查看
- 显示合计答对/答错，以及最近 20 条明细

### `/回答 <答案>`
- 需先注册，且群内正在进行答题
- 选择题：`/回答 A`~`/回答 Z`（超出选项范围会提示"选项不存在"）
- 填空题：`/回答 具体内容`
- 回答过快会被限流（`watingPlay` 配置，默认 10 秒间隔）
- 每题结算时会把昵称、QQ、作答结果写入持久化答题记录

### `/开始抢答`
- 管理员专属；每次只能进行一局
- 回复顺序：题库信息 → 第 1 题

### `/结束本题`
- 管理员专属；立即公布当前题答案并切到下一题
- 重复触发有防重入保护（提示"正在切换题目，请稍候"）

### `/结束抢答`
- 管理员专属；结束整局并结算（重置游戏状态）

### `/答题题目`
- 查看服务器可用题库（本地模式为 `data/answerData/` 下的 json 文件）

### `/休眠` / `/唤醒` / `/休眠状态`
- `/休眠`：管理员专属；有进行中的对局时会拒绝。立即卸载题库并回收空闲房间
- `/唤醒`：立即从磁盘（或云端目录）加载题库
- `/休眠状态`：查看是否休眠、题库是否在内存、进行中的对局数
- 休眠期间普通指令仍可用；`/开始抢答` 会自动唤醒

## 四、配置项说明（插件配置）

| 配置 | 默认值 | 说明 |
|---|---|---|
| `useLocal` | `false` | 使用本地题库（推荐 `true`，离线稳定） |
| `localPath` | `./data/answerData` | 本地题库目录 |
| `answersNumOfRush` | `10` | 每局题目数量 |
| `watingTime` | `60000` | 每轮出题等待时间（毫秒） |
| `watingPlay` | `10000` | 同一人两次回答的最小间隔（毫秒） |
| `autoNext` | `10` | 每题作答时间（秒），结束后公布答案并切题；`0` = 不自动切题 |
| `useGlobalNick` | `false` | 注册时固定用平台昵称（全局统一）；`false` = 优先群名片 |
| `adminQQ` | `[]` | **管理员 QQ 号白名单**（数组，如 `['10001','10002']`） |
| `superAdminQQ` | `[]` | **超级管理员** QQ 号（含管理员权限，可 `/添加管理员`、`/移除管理员`） |
| `atQQ` | `false` | 回复中是否 @ 用户（兼容机制） |
| `debug` | `false` | 控制台调试日志 |
| `highMarkFullCount` | `5` | 3 分题最先作答的若干人答对得满分，其余答对基础分减半 |
| `sleep.enabled` | `true` | 启用空闲休眠 |
| `sleep.idleMinutes` | `20` | 无对局且无指令后等待多少分钟进入休眠；`0` = 不自动休眠 |
| `sleep.startAsleep` | `true` | 启动时不预加载题库，首次开局或 `/唤醒` 时再加载 |
| `sleep.unloadQuiz` | `true` | 休眠时从内存卸载题库 |
| `sleep.autoEndIdleGameMinutes` | `10` | 对局中连续无人作答超过该分钟数则自动结束本局；`0` = 不自动结束 |

## 五、休眠策略（降低空闲占用）

插件在**没有进行中的抢答**时会进入休眠，减少内存里常驻的题库和群房间对象：

- **启动即休眠**（默认）：Koishi 起来后不立刻把题库读进内存，第一次 `/开始抢答` 或 `/唤醒` 才加载
- **空闲自动休眠**（默认 20 分钟）：对局结束且没人再发本插件指令后，卸载题库、回收空闲房间
- **对局看门狗**（默认 10 分钟）：一局开了但一直没人作答，自动结束本局，避免定时器一直跑、题目一直刷
- **手动**：管理员 `/休眠` 立即卸载；任何人 `/唤醒` 立即加载；`/休眠状态` 查看当前状态

休眠期间 `/注册`、`/我的账号` 等普通指令仍可用，不必先唤醒。`/开始抢答` 会自动加载题库。

> 说明：这只能降低**答题插件**自己的内存。NapCat（QQ 协议容器）才是整机占用的大头，需要停容器才能明显降 RAM。

## 六、常见问题

| 问题 | 处理 |
|---|---|
| 命令无反应 | 群聊发 `/指令`，或 @机器人后发指令（可无 `/`）；确认 NapCat 连接正常 |
| `/回答` 提示未注册 | 先发送 `/注册` |
| `/开始抢答` 提示无权限 | 你不是管理员；请超级管理员 `/添加管理员 你的QQ` 或把 QQ 写入 `adminQQ` |
| 答题后没有立即判对错 | 这是设计行为：作答时间结束后统一公布答案 |
| 题目长时间不切题 | 检查 `autoNext` 是否被设为 `0`，或当前题有人作答等待时间结束 |
| 对局莫名自动结束 | 检查 `sleep.autoEndIdleGameMinutes`（默认 10 分钟无人作答会收局）；不需要可设为 `0` |
| 想要更短/更长的答题时间 | 调整 `autoNext`（秒）后重启 Koishi |
| 换题库 | 在 `data/answerData/` 放入 JSON 题库文件（格式参照 `test.json`） |

## 七、部署维护速查（fnOS）

| 操作 | 命令（SSH） |
|---|---|
| 查看容器状态 | `sudo docker ps` |
| Koishi 日志 | `sudo docker logs koishi --tail 50` |
| 重启 Koishi | `sudo docker restart koishi`（NapCat 自动重连，无需重新扫码） |
| 重启 NapCat | `sudo docker restart napcat`（**会导致 QQ 登录态失效，需重新扫码**） |
| 内存占用 | Koishi 上限 256MB、NapCat 上限 512MB；空闲时答题插件会卸载题库。整机大头是 NapCat，不能停容器否则收不到 QQ 消息 |
| Koishi 控制台 | `http://<NAS-IP>:5140` |
| NapCat 面板 | `http://<NAS-IP>:6099`（token 见部署配置 `WEBUI_TOKEN`） |
| 数据目录 | `/vol1/1002/docker/koishi`（配置/数据库/题库持久化） |
